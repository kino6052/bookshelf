Ambient music for the library
=============================

Drop audio files into this folder and they play while you walk around:

  - Formats: .mp3, .ogg, .m4a, .wav (one file per track).
  - The title shown in the corner comes from the filename:
      "01 - Morning Light.mp3"  ->  "Morning Light"
  - Tracks play in a shuffled loop with a 4-second cross-fade.
  - With the dev server running (npm run dev) new files are picked up live.

If this folder has no tracks, the library plays a quiet generated ambient pad instead,
so you never need to add anything.

COPYRIGHT: everything in this folder is published with the site when you deploy it.
Only add music you made yourself or have the right to share publicly
(e.g. CC0 / public-domain recordings, or tracks licensed for redistribution).
